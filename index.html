Interpretasi awal

Masukkan minimal beberapa hari data untuk melihat pola. Perubahan berat harian terutama dapat dipengaruhi air, glikogen, dan isi pencernaan.

Catatan pagi

Input BB dan LP saat bangun pagi, setelah ke toilet dan sebelum makan. Isi kalori yang dikonsumsi kemarin, bukan kalori yang terbakar saat olahraga.

Ukur pada pusar, akhir hembusan napas normal.
Untuk tanggal sebelumnya

Kenapa kalori kemarin?

BB dan LP dicatat pagi ini, sedangkan kalori adalah asupan selama hari sebelumnya. Dengan demikian, kamu dapat melihat hubungan waktu yang benar. Satu hari kalori tinggi tidak berarti langsung menambah lemak; evaluasi tren minimal 2–4 minggu.

LP tidak harus diukur setiap hari. Mengukur 1–3 kali per minggu secara konsisten sering lebih bermanfaat daripada mengukur berulang dengan teknik berbeda.

Target & preferensi

Target awal kalori 1.900 kcal sesuai diskusi; kamu dapat mengubahnya. BB target tidak wajib diisi: fokus body recomposition dapat menggunakan tren LP dan performa latihan.

Backup & keamanan data

Semua catatan tersimpan hanya di browser/perangkat ini. Tidak tersinkron antar HP dan laptop. Simpan backup secara berkala sebelum membersihkan data browser atau mengganti HP.

Cara install

Upload isi ZIP ini ke repository GitHub Pages baru, misalnya bodytrack-app. Buka website di Chrome Android lalu pilih Install app atau Add to Home screen. Website bekerja offline setelah berhasil dibuka dan cache terpasang. Gunakan HTTPS agar PWA dapat diinstal.
