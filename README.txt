BodyTrack — Weight & Waist

INSTALL VIA GITHUB PAGES
1. Create a new public GitHub repository, e.g. bodytrack-app.
2. Upload all 5 files from this ZIP to repository root (not the enclosing folder): index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open the published URL on Android Chrome and select Install app / Add to Home screen.

DATA & PRIVACY
Data is stored locally in the browser via localStorage. No cloud synchronization. Backup JSON in Target & Data regularly. Export CSV for Excel. Do not clear site data without backup.

DATE LOGIC
Record weight/waist in the morning and calories consumed during the preceding day. Calories mean food energy consumed, not exercise calories burned.

Charts show trends; Pearson r is exploratory, not evidence of causality. This app is not a medical device.
